cxy的yolo训练平台 使用说明
=========================

启动：双击 run.bat（首次需先安装界面库）：
  python -m pip install pyside6 -i https://mirrors.aliyun.com/pypi/simple

三个页面：

1) 训练
   - 模型文件：下拉选择（自动扫描常见模型目录），或直接粘贴 .pt 路径
   - 数据集：选择 dataset.yaml，下方自动显示类别数和 train/val 图片数
   - 快捷预设：快速测试 / 标准训练 / 高精度，一键填好参数
   - 开始训练 / 停止训练 / 导出 ONNX / 打开结果文件夹
   - 训练历史：双击列表里的记录可直接打开对应结果文件夹
   - 底部日志实时滚动，顶部进度条显示当前轮数

2) 智能预标注
   - 选模型（用训练好的 best.pt）
   - 选待标注图片文件夹、输出文件夹、置信度
   - 开始后自动生成 YOLO 格式标注 txt + 带框预览图
   - 完成后人工检查预览图，把合格的图片和标注拷进数据集

3) 推理测试
   - 选模型，选一张图片或整个文件夹
   - 输出带检测框的结果图，快速验证模型效果

4) 数据处理
   - 自动数据分类：用训练好的模型把图片按类别归入 <文件夹>/自动分类/<类别>/
   - 批量重命名：分类文件夹内图片改成 前缀_数字（如 early_blight_001.jpg），
     可同步重命名同名 .txt 标注
   - 数据整合：把各分类子文件夹的图片汇总到 main，自动生成 main-labels
     （每张图生成整图标注框，并写出 classes.txt）

5) 模型报告
   - 选训练记录，查看 P/R/mAP50/mAP50-95、训练曲线图、混淆矩阵
   - 一键打开文件夹 / 导出 ONNX / 用该模型推理

常见说明：
   - 训练/预标注都使用当前 Python 环境的 CUDA 版本（cu130，支持 RTX 50 系）
   - AMP 自检需要的 yolo26n.pt 会自动从本地复制，无需联网下载
   - 界面配置会自动记住，下次打开不用重填
